# 食饮出价底层逻辑 · 客户培训

> 腾讯广告 · 食饮行业投放力诊断与提升 · 进阶专题《出价与归因（上）》
> 40min 认知课 · 三幕结构 · 双视觉对偶图

## 一、内容概要

本课程是《食饮投放力诊断与提升》主课的进阶专题，聚焦**出价的底层逻辑**：

- **第一幕 · 模型**：PCVR vs pLTV — 出价不是技术题，是决策题
- **第二幕 · 契约**：CPA 契约 vs ROI 契约 — 前提是天平得先成立
- **第三幕 · 博弈**：成本×拿量天平 — 冷启没有契约，只有让契约有资格存在

## 二、核心视觉

1. **天平四杠杆图**：出价水位 / 归因窗口 / 深度事件 / 契约外能力
2. **模型四边界图**：样本不足 / 金额方差小 / 创意变化快 / 深度事件稀

## 三、三阶心法

```
调参数 → 选杠杆 → 判边界
```
