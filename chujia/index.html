症状
"我转化口径 CVR 都 8% 了，怎么广告就是跑不动？"
回传口径 客户复盘看数 · 投放端常用
转化回传
转化数据"统计到行为上报时间点"。
含历史回流转化——前 N 天的曝光/点击 → 今天才下单，也算今天。
→ 适合实时看当日上报
广告后台示意
┌──────────────────────┐ │ 数据统计口径 │ │ ✓ 转化回传 ←── 你勾的│ │ 广告播放 │ └──────────────────────┘
播放口径 系统喂模型的"真账本"
广告播放
转化数据"统计到广告播放时间点"——
今天这条广告播出去 → 今天这条广告带来的转化，才算。
→ 适合看广告整体生命周期表现，模型只用这部分喂 pCVR
同样 100 单，回传口径看到
今天上报：100 单 ├ 今天广告带来 30 单 ├ 昨天广告带来 25 单 ├ 前天广告带来 28 单 └ 更早回流 17 单
同样这天，播放口径只算

ACT 2·归因前置 · 5 min

今天的转化数，三天后还在变

症状
"昨天报表 50 单，今天再看变 80 单，到底以哪个为准？"
真相

默认归因窗口 = 30 天

一次曝光/点击 │ ├─── T+0 下单 ──→ 计入今天广告 ├─── T+3 下单 ──→ 仍回归到"那一天的广告" ├─── T+15 下单 ──→ 仍回归 └─── T+30 下单 ──→ 最后窗口

所以"今天的数据"其实是滚动数字，T+0 看到的只是"目前为止"。
长决策类目（健康滋补 · 酒水 · 母婴）回流尤其明显。

📊 不同归因窗口的"看数稳定期"

归因窗口看真账
24 小时下单T+1
30 天下单T+7 起
30 天 ROIT+15 最佳
📐 结论： 数据要"看穿时间"。
短链路看 T+1，长链路至少看 T+7、最好 T+15，才是真账。

ACT 3·出价方式心法 · 12 min · 核心一幕

下单出价 vs 下单 ROI
同一个用户，两套模型眼里完全不一样

场景
多品直播间——一个用户通过广告点进直播间，在 3 个不同时刻下了 3 单： 9.9 元尝鲜装 → 89 元礼盒装 → 199 元家庭囤货装。
同一个人、3 笔订单，两套模型分别看到了什么？
USER JOURNEY · 同一个广告点击进来的同一个人
T+0 · 进直播间
9.9 元
尝鲜装
→
T+0 · 30 min 后
89 元
礼盒装
→
T+3 · 3 天后回流
199 元
家庭囤货装 · 总 GMV 297.9
CPA 契约 下单出价

pCVR 模型眼里：这是 1 个转化

第 1 单 9.9 元 ──→ ✓ 转化达成 第 2 单 89 元 ──→ ·· 已转化用户，无价值 第 3 单 199 元 ──→ ·· 已转化用户，无价值 ───────────────────── 模型学到："这种人会下单" 模型在意：下不下单（0 / 1） 模型不在意：下多少钱、买几次

系统会去找"长得像第 1 单这种 9.9 党"的人—— 因为单看 pCVR，9.9 党最容易出单、CVR 最高。

ROI 契约 下单 ROI

pCVR × pLTV 模型眼里：这是一个值 297 元的人

第 1 单 9.9 元 ──→ ✓ 转化 + 金额学习 第 2 单 89 元 ──→ ✓ 复购 + 金额学习 第 3 单 199 元 ──→ ✓ 高客单 + 金额学习 ───────────────────── 模型学到："这种人会买更多" 模型在意：下单 + 总 GMV 模型升维：找会下单 → 找会持续买、买更贵的人

系统会去找"长得像这个会复购、会升单的人"—— 即使 pCVR 略低，但 pLTV 高，消耗 / GMV 反而更划算。

🎁 一句话听懂： 下单出价帮你找"会下单的人"，下单 ROI 帮你找"会买更多的人"。
多品直播间 / SKU 丰富 / 客单跨度大 的客户，用 pCVR 是亏的—— 模型只学到第 1 单，后面 2 单的价值全被它当成噪声丢掉了。

ACT 3.1·一张表看懂模型差异

两种出价的5 个关键差异

维度 下单出价 · CPA 契约 下单 ROI · ROI 契约
系统在赌什么 pCVR（会不会下单） pCVR × pLTV（下单 + 多少钱）
契约对齐什么 单均成本 ≈ bid 消耗 / GMV ≈ 1 / ROI
样本要求 转化数（几十~几百单可起量） 转化数 + GMV 金额方差也要够
学得快不快 ✅ 快（pCVR 单维度） ⏳ 慢（多 pLTV 一层）
怕什么 客单波动大（同一 bid 算所有客单） 金额方差小（全 9.9 元，pLTV 学不出差异）
适合场景 冷启 / 新品 / 客单稳定 / 快速起量 稳态 / SKU 丰富 / 客单跨度大 / ROI 考核
🎁 升维金句： 下单出价是"管成本"，下单 ROI 是"管赚钱"。
冷启阶段，先让系统学会"谁会下单"，再让它学会"谁下单更值钱"。
📍 多品直播间 / SKU 丰富的客户，过了冷启就该切下单 ROI——别让模型只看到第 1 单。

ACT 3.2·选型决策树

心法决策三问

不是看"客户考核什么"就用什么——先看模型有没有学好的资格。

01

样本够不够？

过去 7 天有没有 ≥ 50 单转化？

否 → 下单出价（先把 pCVR 喂出来）
是 → 进入第 2 问
02

客单跨度大不大？

SKU 客单价 最高 / 最低 ≥ 3 倍？

否 → 下单出价（ROI 学不出差异）
是 → 进入第 3 问
03

客户考核什么？

客户的 KPI 是看成本还是看 ROI？

成本 → 下单出价（契约对齐 KPI）
ROI → 下单 ROI（契约对齐 KPI）

🚨 切换的 2 个坑

  • 不要在跑量稳定期切：换契约 = 模型重学 pLTV，必有 3-7 天掉量过渡期
  • 不要在大促前一周切：大场不允许冒险，要切就在大场结束、稳态期切
📐 结论： 下单出价是"先让模型活下来"，
下单 ROI 是"让会赚的模型多赚一点"。

不想等 30 天回流的盘

客户考核净成本而非毛成本

ACT 4·出价杠杆 · 10 min

起不来量，加价就有量——
这是错的吗？

症状
"是不是每次起量都得靠加价？这是不是投手偷懒？"

eCPM 公式：只有 1 个杠杆能直接握在你手里

eCPM = bid × pCTR × pCVR × 1000 ↑ ↑ ↑ 直接 间接 间接（且冷启样本不足）

三个杠杆的"撬动周期"

杠杆谁说了算多久
bid客户直接调秒级
pCTR创意 + 系统几小时~几天
pCVR商品 + 落地页 + 系统冷启最慢

🎯 反直觉锚点

加出价不是"投手偷懒"，是冷启阶段唯一能秒级影响 eCPM 的科学操作。
因为冷启时 pCVR 是预估的、置信度低，系统给的量极少； 这时你不主动用 bid 把 eCPM 顶上去，模型永远等不到那个能让它"开窍"的样本量。

🎁 升维金句： 冷启阶段，bid 不是成本表达，是"模型学习费"。

ACT 5.0·掉量诊断的元决策 · 5 min

救火之前，先想清楚一件事：
你这个广告，更要成本，还是更要量？

元决策
所有出价决策的第一性问题不是"出多少"，而是"这个广告 / 这个阶段，我更需要什么"。
没有这个共识，加价 / 降价 / 换契约都是在打盲拳——掉量了也救不回来。
⚖ COST × VOLUME · 出价天平 · 博弈进行时
⬅ 这局重「成本」：契约保障，忍住别加价
天平倾斜 = 出价决策点
这局重「拿量」：主动加价 / 解杠杆 ➡
控成本优先 利润型 / 爆品稳态
典型场景
  • · 爆品稳定期，ROI 是生命线
  • · 利润敏感（食饮加工 / 标品），CPA 超 1 块都疼
  • · 客户已有稳定模型积累，目标是守 ROI 上限
系统会怎么做

严格履约 → 一旦累计超成本，主动压量回收（就是下一页要讲的"超成本打压"）

掉量时的正确动作

忍住不加价，温和回调到合理水位，等成本回收期度过自然恢复

抢拿量优先 冷启 / 大场 / 清仓
典型场景
  • · 新品冷启，目标是把模型样本灌起来
  • · 大场预热 / 开播加速，前 2 小时定全场
  • · 库存清仓 / 临期，目标客单可让步
系统会怎么做

放宽履约 → 先抢量、后调成本，给系统更宽容忍度去探索

掉量时的正确动作

主动加价 / 加预算 / 解杠杆（如开速推、放宽 ROI 目标），先把量稳住再谈成本

⚠ 最常见的错
立场错位 = 永远救不对火。 把"控成本"客户当"抢量"投 → 一加价就触发超成本打压、量更少；把"抢量"客户当"控成本"投 → 模型永远跑不出冷启、客户骂你佛系。 → 跟客户对齐第一句话永远是："这个广告这个阶段，我们要的是成本还是量？"
📐 元决策金句： 出价不是技术题，是决策题；决策的前提，是天平先得成立。
天平的两端不是给你选"哪个更好"，而是逼你跟客户/老板明牌共识：这局，重在哪头。

ACT 5.1·掉量诊断之"超成本打压" · 5 min

跑得好好的，怎么突然掉量了？

症状
"前两天日耗 5 万好好的，今天突然 8000 都花不出去！"

🩺 触发链路：超成本打压

前期跑量大、单 CPA 偏高 ↓ 系统检测到累计成本超目标 ↓ 进入"成本回收期" 自动下调内部出价（你看到的出价没变） ↓ eCPM 跌穿竞价线 ↓ "突然就没量了"

📐 这不是 bug

ROI / 下单出价是契约型出价——
正面：你给目标，系统帮你达成 → 起量；
背面：累计超成本，系统主动履约 → 压量。

掉量从来不是"突然"的，
是前几天的好量已经"预支"了今天的份额。

🎯 解药：不是简单"再加价"

❌ 错误操作 ✅ 正确动作
直接关停重建 检查近 3 天计价率（cost / gmv 或 cost / 转化数 × bid）
大幅加价压不住 把出价温和回调到合理水位（不是瞎加）
怪系统抽风 理解：这是系统在履约，不是 bug

🆕 创意优投 · 关键认知 3 条

  1. 本质：项目级的素材测试通道，不是创意级；一个源项目最多对应一个优投项目
  2. 预算独立：从账户单独划拨，不占源项目预算，源项目花完仍可投
  3. 提价范围：10%~50%，这是人为设定的"模型学习费"——和第四幕"bid 是模型学习费"完全呼应

🚨 三条避坑红线

  1. 不要叠满：潜客优投 ×1.5 + 创意优投 ×1.3 = 真出价 ×1.95，容易超成本
  2. 不要在掉量当下开：先排查是否"超成本打压"，否则加速器火上浇油
  3. 不要长期常开：加速器是"应急药"，长期开会让客户失去对真实成本的感知

🎨 素材 爆款挖掘

想验证哪个素材能跑？

  • 多素材想找爆款 → 创意优投
  • 新素材冷启验证 → 创意优投（提价 10-50%）
  • 独立预算 · 不占源项目
👥 人群 精准拿量

想多拿"对的人"？

  • 标准化高意向潜客 → 潜客优投
  • 自定义人群分桶 → 分人群出价

🧭 顺序口诀：先时间、后素材、再人群

时间是脉冲（应急启动）→ 素材是验证（找到爆款的图视频）→ 人群是放大（在对的人身上多花钱）。
顺序错了，等于：在错的人身上验证错的素材，做出错的脉冲。
